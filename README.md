# fastfetch-configs
A collection of all the Fastfetch configs I've made<br/>
Feel free to use these as-is, modify them to your liking, or use them as inspiration in your own creations!

Some configs come with an image or text file (for ASCII art) used as the logo, so make sure to grab those too.

## Usage
1. Install [Fastfetch](https://github.com/fastfetch-cli/fastfetch) on your machine. Their repo has detailed installation instructions for like every OS
2. I highly recommend taking a look at [how Fastfetch works](https://github.com/fastfetch-cli/fastfetch#usage) and the [configuration wiki](https://github.com/fastfetch-cli/fastfetch/wiki/Configuration).
3. Clone this repo or download the files you want to use.
4. Install a [Nerd Font](https://www.nerdfonts.com/#home) if you haven't already, as I use those for icons.

Then run fastfetch with a config file like this:
```bash
fastfetch -c [PATH_TO_CONFIG_FILE]
```
I recommend setting an alias for this command in your shell to make things easier :)
